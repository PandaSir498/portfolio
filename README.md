# Portfolio Website - Separated Files

Open `index.html` in your browser.

## Structure

- `index.html` - HTML content/website structure
- `css/style.css` - all styles/design/responsive layout
- `js/script.js` - data, portfolio rendering, modal, carousel, cursor, navigation, contact form
- `assets/images/` - place your photos and project images here
- `assets/icons/` - place icons or logo files here

## Edit guide

- Change colors in `css/style.css` under `:root`
- Change services, skills, projects, and testimonials in `js/script.js`
- Change main text, contact info, and sections in `index.html`
